# 完整交易日志记录增强计划

## 一、需求分析

### 当前日志记录现状

| 日志类型 | 当前状态 | 位置 |
|---------|---------|------|
| 订单成交日志 | ✅ 已有 | `BaseStrategy.notify_order()` |
| 交易闭环日志 | ✅ 已有 | `BaseStrategy.notify_trade()` |
| 回测结束日志 | ✅ 已有 | `BaseStrategy.stop()` |
| 每日资产价值 | ✅ 已有 | `DailyValueObserver` |
| **交易信号日志** | ❌ 缺失 | - |
| **资金状态日志** | ❌ 缺失 | - |
| **持仓状态日志** | ❌ 缺失 | - |
| **订单执行详情** | ⚠️ 部分 | 仅记录成交，缺少提交/状态变化 |

### 需要增加的日志类型

1. **交易信号日志** (`signal_log`)
   - 信号生成时间
   - 信号类型（买入/卖出）
   - 信号触发条件（指标值、价格等）
   - 信号强度/置信度
   - 目标标的

2. **资金状态日志** (`capital_log`)
   - 每日资金快照
   - 可用现金
   - 持仓市值
   - 总资产
   - 资金使用率

3. **持仓状态日志** (`position_log`)
   - 每日持仓详情
   - 持仓成本
   - 持仓盈亏
   - 持仓比例
   - 持仓天数

4. **订单执行日志** (`order_log`)
   - 订单提交（预期价格、数量）
   - 订单状态变化（提交→接受→成交/取消/拒绝）
   - 滑点分析
   - 执行效率

## 二、技术方案

### 2.1 新增日志数据结构

#### 信号日志结构 (`SignalLog`)
```python
@dataclass
class SignalLog:
    datetime: datetime          # 信号时间
    symbol: str                 # 标的代码
    signal_type: str            # 信号类型: buy/sell
    trigger_condition: str      # 触发条件描述
    indicator_values: Dict      # 指标值快照
    confidence: float           # 信号强度 0-1
    target_price: float         # 目标价格
    stop_loss: Optional[float]  # 止损价
    take_profit: Optional[float] # 止盈价
```

#### 资金日志结构 (`CapitalLog`)
```python
@dataclass
class CapitalLog:
    date: date                  # 日期
    cash: float                 # 可用现金
    position_value: float       # 持仓市值
    total_value: float          # 总资产
    cash_ratio: float           # 现金比例
    position_ratio: float       # 持仓比例
    daily_pnl: float            # 当日盈亏
    daily_return: float         # 当日收益率
```

#### 持仓日志结构 (`PositionLog`)
```python
@dataclass
class PositionLog:
    date: date                  # 日期
    symbol: str                 # 标的代码
    size: int                   # 持仓数量
    cost_price: float           # 成本价
    current_price: float        # 当前价
    market_value: float         # 市值
    pnl: float                  # 浮动盈亏
    pnl_ratio: float            # 盈亏比例
    holding_days: int           # 持仓天数
    weight: float               # 权重
```

#### 订单日志结构 (`OrderLog`)
```python
@dataclass
class OrderLog:
    order_id: str               # 订单ID
    datetime: datetime          # 时间
    symbol: str                 # 标的
    action: str                 # buy/sell
    order_type: str             # market/limit
    expected_price: float       # 预期价格
    expected_size: int          # 预期数量
    status: str                 # submitted/accepted/completed/canceled/rejected
    executed_price: float       # 成交价格
    executed_size: int          # 成交数量
    slippage: float             # 滑点
    commission: float           # 手续费
    message: str                # 状态消息
```

## 五、使用示例

### 策略中使用信号日志

```python
class MyStrategy(BaseStrategy):
    def next(self):
        if self.sma_cross > 0:
            # 记录买入信号
            self.log_signal(
                signal_type='buy',
                data=self.data,
                trigger_condition='SMA金叉',
                indicator_values={
                    'sma_short': self.sma_short[0],
                    'sma_long': self.sma_long[0],
                    'close': self.data.close[0]
                },
                confidence=0.8,
                target_price=self.data.close[0] * 1.1,
                stop_loss=self.data.close[0] * 0.95
            )
            self.buy()
```

## 六、注意事项

1. **性能考虑**: 日志记录应尽量轻量，避免影响回测性能
2. **内存管理**: 对于长期回测，考虑分批写入文件
3. **向后兼容**: 新增字段使用默认值，不影响现有代码
4. **日志级别**: 可通过配置控制日志详细程度
