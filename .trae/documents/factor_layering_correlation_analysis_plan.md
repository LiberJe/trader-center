# 因子分层与相关性分析研究计划

## 一、研究目标

创建一个完整的因子研究策略，深入实践和学习：
1. **因子分层分析**：理解不同因子值分组的表现差异
2. **因子相关性分析**：分析因子间的相关关系，避免冗余
3. **多因子组合策略**：构建有效的多因子投资组合

## 二、研究内容

### 2.1 因子选择

选择多个经典技术因子进行研究：

| 因子名称 | 因子类型 | 说明 | 参数 |
|---------|---------|------|------|
| 动量因子 (Momentum) | 技术因子 | 价格N日收益率 | period=20 |
| RSI因子 | 技术因子 | 相对强弱指标 | period=14 |
| 波动率因子 (Volatility) | 技术因子 | 历史波动率 | period=20 |
| 乖离率因子 (Bias) | 技术因子 | 价格与均线偏离度 | period=20, ma_type='sma' |
| MACD因子 | 技术因子 | MACD指标 | fast=12, slow=26, signal=9 |

### 2.2 因子分层分析

**核心功能**：
- 按因子值将股票分成N组（默认5组）
- 计算各组的平均收益、波动率、夏普比率
- 分析多空组合（最高组-最低组）的表现
- 计算单调性指标（判断因子是否单调）

**关键指标**：
- 各组平均收益
- 各组夏普比率
- 多空收益差
- 单调性得分（-1到1，越接近1表示单调性越好）
- 换手率（因子稳定性）

### 2.3 因子相关性分析

**核心功能**：
- 计算因子间的相关性矩阵（Pearson/Spearman）
- 识别高相关性因子对（阈值>0.7）
- 分析因子的自相关性（时间序列稳定性）
- 计算因子与收益的相关性（IC）

**关键指标**：
- 因子间相关系数
- 高相关性因子对
- 因子自相关系数
- 平均相关性（衡量因子独立性）

### 2.4 多因子组合策略

**组合方法**：
1. **等权组合**：各因子权重相等
2. **IC加权**：根据IC均值加权
3. **ICIR加权**：根据ICIR加权
4. **最大化夏普比率**：优化权重配置

**组合评估**：
- 组合IC表现
- 组合分层回测
- 组合因子相关性

## 六、学习要点

### 6.1 因子分层分析学习要点
1. **单调性理解**：好的因子应该呈现单调性，即因子值越大，收益越高（或越低）
2. **多空收益**：最高组与最低组的收益差是衡量因子有效性的重要指标
3. **换手率**：换手率过高会增加交易成本，影响实际收益
4. **分组稳定性**：各组的股票构成应该相对稳定

### 6.2 因子相关性分析学习要点
1. **避免冗余**：高相关性因子会降低组合的多样性
2. **因子独立性**：独立性好的因子能提供独特的信息
3. **时间稳定性**：因子相关性应该在不同时间段保持稳定
4. **IC vs 相关性**：因子间相关性与IC是不同的概念

### 6.3 多因子组合学习要点
1. **加权方法**：不同加权方法适用于不同场景
2. **组合优化**：需要平衡收益、风险和稳定性
3. **因子数量**：并非因子越多越好，需要控制因子数量
4. **动态调整**：因子权重可以根据市场环境动态调整
