## 研究内容

### 1. 因子分层分析

**核心概念**：
- 将股票按因子值分成5组（或自定义组数）
- 计算各组的平均收益、波动率、夏普比率
- 分析多空组合（最高组-最低组）的表现

**关键指标**：
- **单调性**: 衡量因子值与收益的单调关系（-1到1，越接近1越好）
- **多空收益**: 最高组与最低组的收益差
- **多空夏普**: 多空策略的风险调整收益
- **换手率**: 因子值的稳定性

**解读示例**：
```
因子: volatility_20
  单调性: 0.2000        # 正值，表示因子值越大，收益越高
  多空收益: 0.0010       # 正收益，表示多空策略有效
  多空夏普: 0.1137       # 夏普比率，衡量风险调整收益
  平均换手率: 0.1689     # 较低的换手率，因子较稳定
```

### 2. 因子相关性分析

**核心概念**：
- 计算因子间的相关性矩阵
- 识别高相关性因子对（避免冗余）
- 分析因子的独立性和稳定性

**关键指标**：
- **相关性矩阵**: 因子间的相关系数
- **高相关性因子对**: |corr| > 0.7的因子对
- **因子独立性**: 平均相关性越低，独立性越好
- **因子IC**: 因子与未来收益的相关性

**解读示例**：
```
高相关性因子对 (|corr| > 0.7):
  momentum_20 <-> rsi_14: 0.8143      # 高相关，可能存在信息冗余
  momentum_20 <-> bias_20: 0.8383     # 高相关，可能存在信息冗余
  volatility_20 <-> bias_20: 0.022    # 低相关，独立性较好
```

### 3. 多因子组合策略

**组合方法**：
1. **等权组合**: 各因子权重相等
2. **IC加权**: 根据IC均值加权
3. **ICIR加权**: 根据ICIR加权（推荐）

**组合评估**：
- 组合IC表现
- 组合分层回测
- 组合单调性

**解读示例**：
```
ICIR加权组合:
  momentum_20: 0.2529    # 根据ICIR分配的权重
  volatility_20: 0.4954  # ICIR最高，权重最大
  rsi_14: 0.0051         # ICIR较低，权重最小
  
表现:
  IC均值: 0.0045
  ICIR: 0.0316
  多空夏普: 0.0182
```

## 学习要点

### 因子分层分析
1. **单调性是关键**: 好的因子应该呈现单调性
2. **多空收益**: 衡量因子区分度的重要指标
3. **换手率影响**: 换手率过高会增加交易成本
4. **分组稳定性**: 各组股票构成应该相对稳定

### 因子相关性分析
1. **避免冗余**: 高相关性因子会降低组合多样性
2. **独立性重要**: 独立性好的因子提供独特信息
3. **时间稳定性**: 因子相关性应该在不同时期保持稳定
4. **IC vs 相关性**: 因子间相关性与IC是不同概念

### 多因子组合
1. **加权方法**: ICIR加权通常优于等权
2. **因子数量**: 建议3-5个独立因子
3. **动态调整**: 根据市场环境调整权重
4. **组合优化**: 平衡收益、风险和稳定性

## 常见问题

### Q1: 为什么测试版本的因子表现看起来不太好？
A: 测试版本使用随机生成的模拟数据，因子表现是随机的。真实数据会显示更有意义的结果。

### Q2: 如何选择最优的因子组合？
A: 建议选择：
- 单调性好（>0.3）
- IC显著（|IC|>0.02）
- 独立性好（平均相关性<0.3）
- 换手率适中（<0.3）

### Q3: ICIR加权为什么通常更好？
A: ICIR同时考虑了IC的大小和稳定性，能够更好地利用因子信息。

### Q4: 如何解读高相关性因子对？
A: 高相关性因子对可能存在信息冗余，建议：
- 选择表现更好的一个
- 或者通过正交化处理消除相关性
