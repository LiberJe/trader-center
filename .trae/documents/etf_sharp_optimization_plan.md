# ETF-Sharp策略优化计划

## 1. 当前实现分析

### 1.1 当前实现概述

当前ETF-Sharp策略已实现：
- 四因子体系：夏普比率(40%)、动量(25%)、波动率(20%)、最大回撤(15%)
- 归一化处理：Winsorize(2.5%-97.5%) + Z-score标准化
- 权重分配：等权分配或得分加权
- 定期轮动：每20个交易日再平衡

### 1.2 可能与文章存在的差异点

根据常见的ETF Sharp策略最佳实践，当前实现可能存在以下差异：

| 差异点 | 当前实现 | 可能的优化方向 |
|--------|----------|----------------|
| 因子计算窗口 | 夏普比率60天，动量20天，波动率20天，回撤60天 | 统一或动态调整窗口 |
| 归一化方法 | 横截面Z-score | 可能需要时间序列标准化或排名标准化 |
| 因子方向处理 | 在加权时取负 | 可能在标准化前处理 |
| 权重分配 | 等权或得分加权 | 可能需要风险平价或波动率目标 |
| 调仓频率 | 固定20天 | 可能需要信号触发或动态频率 |
| 资产池 | 5个ETF | 可能需要扩展或筛选 |
| 空仓处理 | 无空仓逻辑 | 可能需要市场择时或空仓条件 |

## 3. 优化建议

### 3.1 高优先级优化

#### 优化1: 因子计算细节优化

**当前问题**：
- 因子计算窗口不统一
- 可能使用简单收益率而非对数收益率

**优化方案**：
```python
# 统一使用对数收益率
log_returns = np.log(close / close.shift(1))

# 或使用简单收益率
simple_returns = close.pct_change()
```

**优化文件**：
- `trader_center/factor/library/technical/sharpe.py`
- `trader_center/factor/library/technical/drawdown.py`

#### 优化2: 归一化方法增强

**当前问题**：
- 只支持横截面标准化
- 缺少排名标准化和时间序列标准化

**优化方案**：
- 添加时间序列标准化选项
- 添加排名标准化选项
- 添加去均值化选项

**优化文件**：
- `trader_center/backtest/strategy/factor_scorer.py`

#### 优化3: 权重分配优化

**当前问题**：
- 等权分配不考虑资产风险
- 得分加权可能导致集中度过高

**优化方案**：
- 添加风险平价权重分配
- 添加波动率目标权重分配
- 添加最大权重限制

**优化文件**：
- `trader_center/backtest/strategy/etf_sharp.py`

### 3.2 中优先级优化

#### 优化4: 调仓逻辑优化

**当前问题**：
- 固定频率调仓，不够灵活
- 缺少止损/止盈逻辑

**优化方案**：
- 添加信号触发调仓
- 添加止损/止盈逻辑
- 添加偏离阈值触发

**优化文件**：

**优化文件**：
- `trader_center/backtest/strategy/etf_sharp.py`
